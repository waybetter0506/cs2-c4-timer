|---|---|---|
| [`../README.md`](../README.md) | 第一次接触这个项目的人 | 简介、功能特性、环境依赖、安装、运行命令、使用示例、项目结构、安全边界、已知边界、FAQ |

| [`自成长设计.md`](自成长设计.md) | 要改"自成长/参考成长"的人 | 两条线（检测侧参考成长、时间侧自成长）的数据文件、触发条件、门槛与限幅、缺局排除、验证记录、已知边界 |

**阅读动线**：`../使用教程+原理.md`（或 `../README.md` 的「安装步骤」）先把程序跑起来 →
遇到疑问看「常见问题」与「已知边界」→
要改样式看 `HUD界面说明.md` → 想知道某个数字是怎么量出来的，看 `实机反馈与待办.md` 对应小节 →
想动精度（换方案）先看 `精度方案总览.md`（含安全边界与各方案的安全类别）→
要自己打包发行看 `../tools/package_release.py` 与 `../packaging/`。

**验证三件套**：

```powershell
python -m c4timer test     # 415 项断言（GSI 42 / 状态机 130 / 显示层 64 / 端到端 27 / 应用层 152）
python tools\shot_hud.py   # 界面 9 个状态的截图，肉眼核对样式
python -m c4timer doctor   # 环境体检：CS2 cfg / 端口 / 生效参数
```

**交付前**再加一道（自己打包时用）：

```powershell
python tools\package_release.py    # 自检 -> 编译 -> 组装 -> 发行包校验
python tools\smoke_release.py      # 真 exe 冒烟：冻结路径 + 数据目录，8 项
```
